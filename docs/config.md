## Integration points
- **Database:** MySQL through JNDI (see above). This is the only back-end integration.
- **Browser-side CDNs:** the pages load Bootstrap 5.3.8 (CSS and bundle JS) on every page and, on table pages, jQuery 3.7.1 and DataTables 2.3.8 with its Bootstrap 5 integration, all from cdn.jsdelivr.net npm paths (`WEB-INF/tags/layout.tag:24-43`, `login.jsp:15-16`). There's no other CDN host since the 2026-10-01 UI redesign (code.jquery.com, cdn.datatables.net and cdnjs.cloudflare.com are no longer used). Every link carries an SRI `integrity` hash and `crossorigin="anonymous"`, so a changed file is blocked by the browser. The pages need internet access to look right.
- **Not found:** messaging, REST clients, email, file transfer (`pom.xml`).
